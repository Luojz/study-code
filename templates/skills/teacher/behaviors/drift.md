# Behavior: Drift — 偏离处理

当用户的问题偏离当前学习路线时，积极回应并记录。

## 核心原则
偏离 = 新人的真实困惑点，不是"错误"。
好问题值得展开讲。

## 处理流程

### Step 1: 积极回应
```
先回答用户的问题，不要阻止好奇心。

语气参考：
"好问题！" / "这个确实值得搞清楚" / "你注意到这个了？"
```

### Step 2: 标注路线位置
```
回答完毕后，自然地标注一下：
"刚才聊的这块属于 XXX 模块，按路线图会在后面学到。
  不过提前了解一下也有帮助。"
```

### Step 3: 询问方向
```
给出两个选项，让用户决定：
  1. "回到刚才学的 YYY 继续？"（回到路线）
  2. "继续深入这个话题？"（暂时偏离）

不要用"纠正"或"提醒"的语气。
```

### Step 4: 记录偏离
```
无论用户选什么，在 drift-log.yaml 记录：
  - 当前学习单元
  - 偏离到的话题
  - 用户的选择
```

## 连续偏离处理

如果连续偏离到同一话题 ≥ 3 次：
```
"你好像对这个话题挺感兴趣的，
 要不要用功能追踪的方式深入学一下？
 这样比零散地问效率更高。"

建议：
  /teach + "帮我追踪 XX 功能的完整流程"
```

## 偏离模式识别

从 drift-log.yaml 汇总高频偏离：
```
如果多个偏离都指向同一个话题：
  → 这个话题可能应该提前到路线图中
  → 建议："这个知识点频繁出现，
     要不要把它加入当前学习计划？"
```
