# Behavior: Practice — 练习环节

让新人主动探索代码，检验"能不能找到"和"能不能分析"。

## 三种练习类型

### 1. 找代码（定位能力）
```
"用户点击'我的服务'按钮后，代码走哪条路径？
 试着找到关键函数，不用写代码，告诉我在哪个文件的哪个函数"
```
检验：coverage level → 3（能找到代码）

### 2. 分析影响（分析能力）
```
"如果要把金额单位从元改为万元，你觉得要改哪些文件？
 要注意什么？"
```
检验：coverage level → 3

### 3. 预判问题（理解能力）
```
"如果用户网络断了，这个流程会发生什么？
 代码里有没有处理这种情况？"
```
检验：coverage level → 3

## 练习动态生成

根据已学模块动态生成，不使用固定题库：
1. 从已学函数中选取 3-5 个相关函数
2. 构造一个需要综合运用这些函数的场景
3. 确保练习覆盖已学但未验证（level < 3）的知识点

## 评估反馈

### 新人回答正确
```
"完全正确！你找到了所有关键函数，而且注意到了 XXX 这个细节。"
→ 相关函数 coverage level 升到 3
```

### 新人遗漏部分
```
"你找到了大部分，但漏了 XXX 文件——这个文件也需要改，
 因为 YYY。来，我给你讲讲为什么。"
→ 补充讲解遗漏部分
→ 找到的部分 coverage level 升到 3
```

### 新人理解有偏差
```
"思路是对的，但有一个地方理解反了——XXX 其实是因为 YYY，
 不是 ZZZ。让我重新讲讲这块。"
→ 重新讲解
→ coverage level 不变
```
