# Study-Code: AI代码教学系统

像老同事带新人一样，帮你学习代码库。支持两种学习模式，智能引导，跨对话进度持久化。

## 快速开始

```bash
# 1. 初始化学习系统
/teach:init

# 2. 开始学习（与自然对话）
/teach:teach
```

## 两种学习模式

### 模式 A：功能故事法（目标驱动）
- "我要改交易功能" → 从交易功能入口追踪完整调用链
- 适合：有明确开发任务，快速定位要改的代码

### 模式 B：分层递进法（系统学习）
- 从入口点开始，按依赖关系逐步展开
- 适合：系统学习整个代码库，建立完整认知

## 核心特性

### 1. 渐进式扫描（Lazy Scanning）
- 只展开你想要学习的代码节点
- Token 消耗随学习进度增长，而非项目大小
- 4 层展开：L0(项目根) → L1(目录) → L2(文件) → L3(函数组)

### 2. DAG 学习路线图
- 自动发现代码依赖关系，构建学习 DAG
- 节点状态：未发现 → 已发现 → 已展开 → 学习中 → 已掌握
- 依赖关系：自动追踪 require/import，建立学习前置条件

### 3. 5 层覆盖率追踪
- Level 0：已发现（知道有这个函数）
- Level 1：听过（听过讲解）
- Level 2：能复述（能用自己的话说）
- Level 3：能找到（能定位到代码）
- Level 4：能修改（通过实战模拟验证）

### 4. 心智模型引导
- 先建立架构认知，再深入代码细节
- 每个新模块定位在架构图中的位置
- 逐步完善心智模型，避免"只见树木不见森林"

### 5. 会话恢复
- 精确到函数级别的断点恢复
- 跨对话进度持久化
- 自然语言摘要上次对话内容

## 命令列表

### 核心命令

| 命令 | 说明 |
|------|------|
| `/teach:init` | 初始化学习系统（4 维度摸底 + 项目扫描） |
| `/teach:teach` | 主学习命令（智能引导 + 自然对话） |
| `/teach:help` | 查看所有命令和使用说明 |

`/teach:teach` 支持自然语言理解，以下功能都通过自然对话触发：
- "展开 vue 目录" → 展开节点
- "交易按钮怎么实现的" → 追踪功能路径
- "有哪些没学的" → 检查盲区
- "考考我" / "练练手" → 提问验证 / 练习

## 状态文件

学习进度保存在 `.study-code/` 目录：

| 文件 | 说明 |
|------|------|
| `config.yaml` | 学习者配置（引导强度、提问频率） |
| `progress.yaml` | 当前进度（光标位置、会话统计） |
| `roadmap.yaml` | 学习 DAG（节点、边、状态） |
| `coverage.yaml` | 覆盖率（函数级别 4 层追踪） |
| `tree-state.yaml` | 树展开状态（已展开/发现的节点） |
| `snapshot.md` | 会话快照（精确断点恢复） |
| `mental-model.md` | 心智模型（架构认知） |
| `drift-log.yaml` | 偏离日志（问题记录） |

## 使用示例

### 初次使用
```
你: /teach:init
老师傅: 你好！我是来帮你熟悉这个代码库的。先了解下你的背景...
       （4 维度摸底）
       好的，我了解了... 建议从 index.js 开始学。
       输入 `/teach:teach` 开始学习。
```

### 继续学习
```
你: /teach:teach
老师傅: 上次你学到 init() 函数的 native 桥接部分...
       要继续吗？
```

### 自然对话
```
你: 交易按钮怎么实现的？
老师傅: 好问题！让我帮你追一下这个功能的路径...
       （追踪功能路径）
       用户点击 → handleClickTrade() → checkLogin() → ...
```

### 查漏补缺
```
你: 有哪些没学的？
老师傅: 让我看看... 有这些盲区：
       - init() 函数（入口，被 12 处引用）
       - fetchData() 函数（数据请求，被 8 处引用）
       ...
```

## 学习节奏

系统根据你的经验自动调整：
- **新手**：详细讲解 + 频繁提问 + 手把手引导
- **中等**：标准讲解 + 适度提问 + 建议顺序
- **老手**：简明讲解 + 低频提问 + 自由探索

## 偏离处理

你的问题就是学习信号：
- 问到未学内容 → 积极回答 + 标注路线位置
- 连续问同一话题 ≥ 3 次 → 建议深入学习该话题
- 所有偏离记录在 `drift-log.yaml`

## 实战验证

学习到一定程度后，系统会：
1. 出练习：定位代码 / 分析影响 / 预判问题
2. 模拟需求：给出真实场景需求，检验独立分析能力
3. 通过实战 → coverage level → 4（可以开始做真实需求）

## 技术实现

- **Claude Code Skills**: AI 行为定义在 `.claude/skills/teacher/`
- **命令触发器**: CLI 命令在 `.claude/commands/teach/`
- **状态持久化**: YAML + Markdown 文件
- **编排器模式**: 单一入口 (`orchestrator.md`) 读取状态、决策、路由到行为
